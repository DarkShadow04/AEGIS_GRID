# Naming — AEGIS GRID

**Chosen name: AEGIS GRID**

Reasoning:
- "Cipher" carries the security/offense-defense duality theme you've built your
  whole professional identity around (CEH, red/blue team framing, the
  Dark_Shadow04 persona) without being a generic "security" or "shield" word.
- "Grid" matches what the tool actually is now — a command grid of live
  panels (telemetry, quota, scans, chat), not a single script.
- It reads as a real product name, not a personal project name — important
  since you're releasing this publicly.
- Short, ownable, no direct collision with a major existing security product
  at time of writing (worth a trademark/domain search before you publish).

Alternates, if you want a different direction:
- **OBSIDIAN SENTINEL** — leans harder into the dark/duality aesthetic from
  your portfolio work, more cinematic, slightly longer to say.
- **NEXUS PRIME** — keeps a direct lineage from "ShadowNexus," signals
  evolution rather than a clean break.
- **VANTAGE GRID** — more corporate/enterprise-sounding, less personal brand,
  good if you want this to read as a SaaS product eventually.

Everything in this build uses "AEGIS GRID" in code comments, the banner, and
the README — swap it with a find-and-replace if you land on a different name.

## Update — renamed again to AEGIS GRID

"CIPHERGRID" read as a cracking/exploitation tool name rather than a defensive
security product, which wasn't the intent. Renamed to **AEGIS GRID** — Aegis
is the protective-shield framing (mythological, defensive), Grid keeps
continuity with the command-center concept, and neither word carries any
"cipher/crack/exploit" connotation. All source, generated reports, and
filenames updated to match.
